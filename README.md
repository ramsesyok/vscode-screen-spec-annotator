# Screen Spec Annotator

スクリーンショットに矩形と丸番号を付けて、画面設計書・画面仕様書の項目を整理するVS Code拡張です。

## 開発版を起動する

1. デスクトップ版VS Codeでこのフォルダーを開き、ターミナルで `npm ci` を実行します。
2. F5で「Screen Spec Annotator」の Extension Development Host を起動します。
3. 開発ホストで画像が入ったフォルダーを開き、PNGまたはJPEGを右クリックして「画面注釈を作成」を選びます。保存先には仕様ごとのフォルダーを指定できます。
4. ツールバーの「矩形を追加」を選び、画像上の図形がない場所からドラッグします。下の表で名称を入力します。矩形を移動すると丸番号も相対位置を保って移動します。丸番号をドラッグすると、丸番号だけを動かせます。
5. Ctrl+S／Cmd+Sで保存し、作成した `*.annotations.json` を開き直すと注釈が復元されます。

### 図形を調整する

- 矩形を選び、Ctrl+C／Ctrl+V（macOS は Cmd+C／Cmd+V）でコピー・貼り付けできます。矩形の右クリックで「矩形をコピー」、画像の空白や矩形の右クリックで「矩形を貼り付け」を選べます。複数選択にも対応し、コピーした矩形、丸番号、名称、個別スタイルを新しい番号で複製します。

- 画像上のツールバーに位置揃え・整列のボタンがあります。幅が足りないときはグループごと次の行に折り返します。画像の右側には座標・サイズの数値入力とスタイルの設定があります。下部の対応表では番号・選択状態を確認し、名称を編集できます。上段と対応表の境界をドラッグすると高さを調整できます。
- 丸番号を右クリックすると、対応する矩形の角、辺の中央、真ん中の9か所から移動先を選べます。「中央」は矩形の真ん中に丸番号の中心が重なる位置です。
- 矩形を追加するときの丸番号の初期位置は、VS Code の設定 `screenSpecAnnotator.defaultMarkerPosition` で変更できます。右クリックメニューと同じ9か所から選べ、既定値は「右上」です。丸番号の中心を指定した位置に置き、画像の端では円が収まる位置まで調整します。変更は次の矩形の追加から有効になります。
- 最初は「図形を選択」モードです。図形がない場所からドラッグすると、枠内に完全に入った矩形と丸番号が選ばれます。Shift＋ドラッグでは枠内の図形を現在の選択に追加できます。
- 矩形や丸番号をクリックすると個別に選べます。Ctrl／Cmd＋クリックまたは Shift＋クリックで追加・解除し、空白をクリックすると選択を解除します。対応表のチェックボックスでは同じ項目の矩形と丸番号をまとめて選べます。
- Esc で選択を解除できます。Delete は選択した図形に対応する注釈項目をまとめて削除します。名称などの入力欄では通常の文字削除として使えます。範囲選択の枠には画像の共通線色を使います。
- 矩形を含む複数の図形を選択しているときに丸番号の右クリックメニューを使うと、選択した各矩形の丸番号を同じ規定位置に移動します。
- 選択した図形は画像上で青い破線と白い縁取りで表示されます。選択した矩形の内側には、画像が透けて見える薄い青の色が付きます。
- 矩形か丸番号のどちらを選んでも、対応する項目の矩形の位置・サイズと丸番号の中心位置を原画像のピクセル単位で入力できます。複数項目で値が異なる欄には「混在」と表示されます。「座標を適用」または Ctrl＋S／Cmd＋S で、入力した欄を選択中の全項目に適用します。
- 位置揃えと整列は選択した図形を対象にします。矩形を選んだ項目では矩形の端や中心を基準にし、丸番号は矩形に追従します。丸番号だけを選んだ項目では、円の端や中心を基準に丸番号を動かします。
- 対象が3つ以上あると、「左右に整列」「上下に整列」で図形間のすき間を均等にできます。両端の図形を固定し、残りを現在の位置順に配置します。両端の間に収まらない場合は、先に選択範囲を広げてください。
- 「共通スタイル」で、注釈の色・線種・線の太さ・丸番号の直径を設定できます。1項目を選ぶと「項目のスタイル」で個別に上書きできます。個別の太さや直径を空欄に戻すと共通設定を使います。
- 「共通スタイル」の「新規画像の既定スタイルにする」で、現在の共通スタイルを VS Code のユーザー設定 `screenSpecAnnotator.defaultStyle` に保存します。次に作成する注釈に適用されます。既存の注釈を開くとファイルに保存されたスタイルが表示されます。
- 線の太さは画面上のpxで指定し、ズームしても太さを保ちます。丸番号の直径は原画像のpxで指定します。共通の直径を空欄にすると自動サイズに戻ります。丸番号が画像からはみ出す場合は、画像内に収まる最小限の移動を行います。

注釈ファイルは6文字の項目IDを持つ形式バージョン2です。旧バージョンの注釈を編集する場合は、初版の拡張を使用してください。

型チェックは `npm run check`、ビルドは `npm run build` で実行します。

## VSIXでインストールする

VS Codeの拡張機能ビューのメニューで「VSIXからのインストール」を選び、`vscode-screen-spec-annotator-0.1.0.vsix` を指定します。操作ボタンのMaterial IconsはVSIXに同梱されているため、インストール後はオフラインでも表示されます。ボタンの機能名はポインターを重ねると確認できます。

VSIXを作り直す場合は、Node.js 22以上で `npm ci` の後に `npm run package:vsix` を実行します。ライセンス情報は [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) を参照してください。

最初の実装は、原画像を相対パスで参照する注釈ファイルの作成・編集・保存に対応しています。共有列の設定、並べ替えと再付番、差し替え後の位置確認、設計書向けの出力は後続の実装範囲です。
