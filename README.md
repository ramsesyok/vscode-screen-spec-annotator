# Screen Spec Annotator

スクリーンショットに矩形と丸番号を付けて、画面設計書・画面仕様書の項目を整理するVS Code拡張です。

## 開発版を起動する

1. デスクトップ版VS Codeでこのフォルダーを開き、ターミナルで `npm ci` を実行します。
2. F5で「Screen Spec Annotator」の Extension Development Host を起動します。
3. 開発ホストで画像が入ったフォルダーを開き、PNGまたはJPEGを右クリックして「画面注釈を作成」を選びます。保存先には仕様ごとのフォルダーを指定できます。
4. 画像をドラッグして矩形を追加し、下の表で名称を入力します。丸番号をドラッグすると、矩形とは別に位置を変えられます。
5. Ctrl+S／Cmd+Sで保存し、作成した `*.annotations.json` を開き直すと注釈が復元されます。

### 図形を調整する

- 項目を1つ選択すると、原画像のピクセル単位で矩形の位置とサイズ、丸番号の中心位置を入力できます。「座標を適用」または Ctrl+S／Cmd+S で確定します。
- 表のチェックボックスで複数項目を選択すると、選択範囲の端や中心を基準に矩形を揃えられます。
- 矩形を3つ以上選択すると、「左右に整列」「上下に整列」で矩形間のすき間を均等にできます。両端の矩形を固定し、残りを現在の位置順に配置します。両端の間に収まらない場合は、先に選択範囲を広げてください。
- 「共通スタイル」で画像内の注釈の色と線種を設定できます。「項目のスタイル」で、選んだ項目の色や線種だけを上書きできます。

注釈ファイルは6文字の項目IDを持つ形式バージョン2です。旧バージョンの注釈を編集する場合は、初版の拡張を使用してください。

型チェックは `npm run check`、ビルドは `npm run build` で実行します。

## 実装状況

最初の実装は、原画像を相対パスで参照する注釈ファイルの作成・編集・保存に対応しています。共有列の設定、並べ替えと再付番、差し替え後の位置確認、設計書向けの出力は後続の実装範囲です。
