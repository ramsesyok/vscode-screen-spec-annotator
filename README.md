# Screen Spec Annotator

スクリーンショットに矩形と丸番号を付けて、画面設計書・画面仕様書の項目を整理するVS Code拡張です。

## 開発版を起動する

1. デスクトップ版VS Codeでこのフォルダーを開き、ターミナルで `npm ci` を実行します。
2. F5で「Screen Spec Annotator」の Extension Development Host を起動します。
3. 開発ホストで画像が入ったフォルダーを開き、PNGまたはJPEGを右クリックして「画面注釈を作成」を選びます。保存先には仕様ごとのフォルダーを指定できます。
4. ツールバーの「矩形を追加」を選び、画像上の図形がない場所からドラッグします。下の表で名称を入力します。矩形を移動すると丸番号も相対位置を保って移動します。丸番号をドラッグすると、丸番号だけを動かせます。
5. Ctrl+S／Cmd+Sで保存し、作成した `*.annotations.json` を開き直すと注釈が復元されます。

### 図形を調整する

- 矩形を選び、Ctrl+C／Ctrl+V（macOS は Cmd+C／Cmd+V）でコピー・貼り付けできます。矩形の右クリックで「矩形をコピー」、画像の空白や矩形の右クリックで「矩形を貼り付け」を選べます。複数選択にも対応し、コピーした矩形、丸番号、名称、個別スタイルを新しい番号で複製します。

- 画像上のツールバーに位置揃え・整列のボタンがあります。幅が足りないときはグループごと次の行に折り返します。画像の右側には座標・サイズの数値入力とスタイルの設定があります。下部の対応表では番号・名称・行順を編集できます。上段と対応表の境界をドラッグすると高さを調整できます。
- ツールバーの「番号の配置」で、選択した項目の丸番号を矩形に対する9か所から一括配置できます。丸番号の右クリックメニューでも規定位置を選べます。「中央」は矩形の真ん中に丸番号の中心が重なる位置です。
- 矩形を追加するときの丸番号の初期位置は、VS Code の設定 `screenSpecAnnotator.defaultMarkerPosition` で変更できます。右クリックメニューと同じ9か所から選べ、既定値は「右上」です。丸番号の中心を指定した位置に置き、画像の端では円が収まる位置まで調整します。変更は次の矩形の追加から有効になります。
- 最初は「図形を選択」モードです。図形がない場所からドラッグすると、枠内に完全に入った矩形と丸番号が選ばれます。Shift＋ドラッグでは枠内の図形を現在の選択に追加できます。
- 矩形や丸番号をクリックすると個別に選べます。Ctrl／Cmd＋クリックまたは Shift＋クリックで追加・解除し、空白をクリックすると選択を解除します。対応表のチェックボックスでは同じ項目の矩形と丸番号をまとめて選べます。
- Esc で選択を解除できます。Delete は選択した図形に対応する注釈項目をまとめて削除します。名称などの入力欄では通常の文字削除として使えます。範囲選択の枠には画像の共通線色を使います。
- 矩形を含む複数の図形を選択しているときに丸番号の右クリックメニューを使うと、選択した各矩形の丸番号を同じ規定位置に移動します。
- 選択した図形は画像上で青い破線と白い縁取りで表示されます。選択した矩形の内側には、画像が透けて見える薄い青の色が付きます。
- 矩形か丸番号のどちらを選んでも、対応する項目の矩形の位置・サイズと丸番号の中心位置を原画像のピクセル単位で入力できます。複数項目で値が異なる欄には「混在」と表示されます。「座標を適用」または Ctrl＋S／Cmd＋S で、入力した欄を選択中の全項目に適用します。
- 位置揃えと整列は選択した図形を対象にします。矩形を選んだ項目では矩形の端や中心を基準にし、丸番号は矩形に追従します。丸番号だけを選んだ項目では、円の端や中心を基準に丸番号を動かします。
- 対象が3つ以上あると、「左右に整列」「上下に整列」で図形間のすき間を均等にできます。両端の図形を固定し、残りを現在の位置順に配置します。両端の間に収まらない場合は、先に選択範囲を広げてください。
- 「共通スタイル」で、矩形の枠線色・線種、注釈の線の太さ、番号の直径・枠線色・背景色・文字色を設定できます。番号の枠線は常に実線で、枠線色が未指定の場合は対応する矩形と同じ色になります。1項目を選び「項目スタイルの個別設定」にチェックを入れると、その項目の現在のスタイルを引き継いで編集できます。チェックを外すと、すべて共通スタイルに戻ります。
- 「共通スタイル」の「新規画像の既定スタイルにする」で、現在の共通スタイルを VS Code のユーザー設定 `screenSpecAnnotator.defaultStyle` に保存します。次に作成する注釈に適用されます。既存の注釈を開くとファイルに保存されたスタイルが表示されます。
- 線の太さは画面上のpxで指定し、ズームしても太さを保ちます。番号の直径は原画像のpxで指定します。直径を空欄にすると自動サイズになります。番号が画像からはみ出す場合は、画像内に収まる最小限の移動を行います。

### 対応表の番号・行順を変更する

- **個別に変更**するには、表の「#12」などの番号をダブルクリックします。その場で空いている正の整数を入力し、Enter または入力欄からのフォーカス移動で確定します。Esc で取り消せます。キーボードでは番号にフォーカスして F2 でも編集できます。
- **行を移動**するには、右端の「⠿」をドラッグし、移動先の行の上端または下端に表示される線でドロップします。番号は各項目と一緒に移動します。キーボードでは「⠿」にフォーカスして上下キーで移動できます。
- **一括で変更**するには、「一括再付番」を押します。全行の変更前後の番号と名称を確認し、「確定」で上から1、2、3…と振り直します。「取消」で元の表に戻れます。

### 対応表を CSV に出力する

表の左上の「画面ID入力」に画面を識別する値を入力し、右上の「一覧出力」を押します。画面IDは注釈ファイルに保存されます。出力先は `output/<注釈名>.csv` で、画面ID・項目ID・表示番号・名称を一覧順に UTF-8 BOM 付きで書き出します。Excel に取り込むときは両方の ID を文字列に指定してください。複数画面を集約する場合は画面ごとに異なる画面IDを使い、再付番後も画面IDと項目IDの組で追加属性を照合できます。

確定した番号は画像上の丸番号にも反映されます。標準の丸番号には2桁まで同じ大きさで表示できます。桁数が増えて円が大きくなるときは、画像内に収まる分だけ中心を内側へ移します。新しい項目には、過去に使用した最大番号の次の番号を割り当てます。

### 注釈付き PNG を出力する

画像ツールバーの「PNGを出力」を選ぶと、矩形と丸番号を原画像の解像度で合成します。たとえば `検索画面.annotations.json` からは、同じフォルダー内の `output/検索画面.annotated.png` に出力します。編集中の変更がある場合は「保存して出力」を選びます。同名の PNG がある場合は上書きの確認が表示されます。出力には確認済みの原画像を使います。

注釈ファイルは6文字の項目IDを持つ形式バージョン2です。旧バージョンの注釈を編集する場合は、初版の拡張を使用してください。

型チェックは `npm run check`、ビルドは `npm run build` で実行します。ビルド時に Excel 手順書の HTML を生成するため、開発環境では Quarto をインストールし、`quarto` を PATH に追加してください。

Node.js 22.18 以降では `npm test` でモデル・送信キュー・通信形式の回帰試験を実行できます。実際の VS Code 文書を使う試験は「実行とデバッグ」の「Screen Spec Annotator 文書編集の統合試験」で起動します。Webview での保存操作は[保存・競合の確認手順](docs/save-baseline.md)で検証できます。

Python 3 と Python 版 Playwright がある環境では、`npm run test:webview` で本番バンドルをビルドし、専用プロファイルの VS Code でドラッグ中の外部更新、名称の競合、寸法不一致、保存後のJSONを確認できます。`VSCODE_EXECUTABLE` でデスクトップ版の実行ファイルを指定します。Windows では PATH 上の `code` からも検出します。

ドラッグ中に対象の位置や原画像の基準が変わると、その操作は中止されます。名称の競合時は入力欄に自分の下書きが残り、最新の名称を見て再適用か破棄を選べます。画像と注釈の基準寸法が異なる間は、座標・丸番号の直径・項目削除をロックします。名称や色は引き続き編集できます。

## VSIXでインストールする

VS Codeの拡張機能ビューのメニューで「VSIXからのインストール」を選び、`vscode-screen-spec-annotator-0.2.0.vsix` を指定します。操作ボタンのMaterial IconsはVSIXに同梱されているため、インストール後はオフラインでも表示されます。ボタンの機能名はポインターを重ねると確認できます。

コマンドパレットで **Screen Spec Annotator: Excel連携の手順を開く** を選ぶと、同梱の手順書を VS Code 内のタブで読めます。目次から各章に移動でき、オフラインでも利用できます。

VSIXを作り直す場合は、Node.js 22以上と Quarto が使える環境で `npm ci` の後に `npm run package:vsix` を実行します。ライセンス情報は [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) を参照してください。

## GitHub Releasesに公開する

リリースするバージョンを `package.json` と `package-lock.json` に反映してデフォルトブランチにマージします。GitHubの **Actions → Release VSIX → Run workflow** でデフォルトブランチを選んで実行します。型チェックとテストが通ると、VSIXを作成し、実行対象のコミットに `v<バージョン>` タグを付けて、リリースノートとVSIXをGitHub Releasesに公開します。

## 実装状況

原画像を相対パスで参照する注釈ファイルの作成・編集・保存、注釈付き PNG と対応表 CSV の出力に対応しています。共有列の設定、差し替え後の位置確認、Markdown の出力は後続の実装範囲です。

[要件定義](docs/requirements.md)・[実装設計](docs/design.md)・[Excelで画面一覧と追加属性を管理する手順](docs/how-to-excel/index.qmd)

Excel 手順書の PDF は、Quarto と BIZ UDGothic が使える環境で `quarto render docs/how-to-excel --to typst` を実行すると `docs/how-to-excel/_book/how-to-excel.pdf` に生成されます。
