# 開発ホストでの保存・競合の回帰確認

検証環境は Windows x64。同じ端末の `code --version` は 1.146.0（69047191fc）。

Windows の Extension Development Host で、テスト専用フォルダーに注釈ファイルからの相対パスを持つ v2 注釈と 320×200 の PNG を置く。矩形 X=30、丸番号 X=90 の項目を一つ用意する。自動保存をオフにし、注釈を Screen Spec Annotator で開く。

| 操作 | 改修前に確認した結果 |
| --- | --- |
| 名称に「-保存」を追記し、矩形 X の入力欄を 50 に書き換え、適用せず File → Save | 名称入力で dirty になり、保存で dirty が消える。保存ファイルには新しい名称、矩形 X=30、丸番号 X=90。入力欄には 50 が残る。 |
| そのまま別プロセスで保存ファイルの矩形 X を 70、丸番号 X を 130 に変更 | 図形と丸番号の欄は外部変更に追従し、矩形 X の入力欄は 50 を保持する。 |
| 矩形 X にフォーカスして Ctrl+S | ディスク上は矩形 X=50、丸番号 X=110。名称は保持される。 |

この結果は現行動作の比較用。メニュー保存時にも座標を確定するかは別の仕様判断とする。

R3・R4 適用後に開発ホストを再読み込みし、初期 X=50、入力 X=60、外部編集 X=70 で同じ手順を再実行した。メニュー保存後のファイルは X=50、外部編集後の入力欄は 60、Ctrl+S 後のファイルは矩形 X=60、丸番号 X=120 だった。

同じ一時ワークスペースで `files.autoSave` を `afterDelay`、待機を 800 ms に設定した。X=85 を未適用のまま名称を追記すると、ディスク上は新名称と X=60 だった。「座標を適用」で矩形・丸番号が (85, 145)、Ctrl+Z で (60, 120)、Ctrl+Y で (85, 145) に戻ることを画面で確認した。ここでの数値の組はそれぞれの X 座標を表す。

自動保存をオフに戻し、名称への追記で dirty になったタブを Ctrl+W で閉じた。VS Code の確認で Save を選ぶとディスクに追記が残り、エクスプローラーから開き直した表にも同じ名称が表示された。さらに名称に `-discard` を追記して同じ手順で Don't Save を選ぶと、ディスク上の名称は直前に保存した値を保持していた。

## 日本語 IME の変換候補表示中の Ctrl+S

利用者による実機確認では、すでに未保存の変更がある状態で日本語を入力し、変換候補が表示されている間に Ctrl+S を押しても保存されなかった。確定済みの日本語文字列の保存は別の手順で確認済み。

名称欄は変換確定時に編集を送信する。Webview の保存キー処理は、キーイベントの `isComposing` が真なら保存要求を送る前に終了する。今回の操作でキーイベントが Webview に届いたかは未計測。変換中の Ctrl+S で、それ以前の確定済み変更だけでも保存すべきかは、保存仕様の判断事項として残す。

## 最低対応版と EXIF 向き付き JPEG

Windows x64 で Microsoft 配布の VS Code 1.95.0 を専用の一時プロファイルで起動し、開発ホストの `vscode.version` が `1.95.0` であることを確認した。文書操作の統合テストでは、同じ版からの連続編集で古くなった要求の拒否、文書をまたぐコピーと貼り付け、不正な編集時の文書保持、保存後のディスク内容の照合がすべて成功した。

画像には、左上が赤、右上が緑、左下が青、右下が黄の 160×96 の JPEG を使い、EXIF Orientation だけを 1〜8 に変えた。各ファイルを実際のカスタムエディターで開き、Pillow の `ImageOps.exif_transpose` から得た寸法と各色領域の中心の RGB を、Webview の Canvas と照合した。さらに、赤の中心に置いた矩形と青の中心に置いた丸番号について、SVG の画面上の位置を画像座標に戻して比較した。

| EXIF Orientation | 表示寸法 | 四つの色の位置・注釈位置・座標編集の可否 |
| --- | --- | --- |
| 1〜4（反転・180°回転を含む） | 160×96 | 4件すべて期待どおり。座標編集が有効 |
| 5〜8（縦横の入れ替えを伴う回転・反転） | 96×160 | 4件すべて期待どおり。座標編集が有効 |

Orientation 6 では、画面で名称を変更し、矩形 X を 65 から 67 に入力して Ctrl+S を押した。ディスク上の JSON で名称と矩形 X=67、追従した丸番号 X=26 を確認した。タブを閉じて開き直した後も、名称と両図形の表示位置が保存値と一致した。
